# Open Pea Server (Vercel Standalone Edition)

Полностью автономный проект для Vercel без внешних VPS, белых IP и дополнительных переменных окружения.

## Как это работает
1. При нажатии кнопки **«Запустить сервер»** Go-бэкенд на Vercel поднимает сессию креатив-сервера и возвращает текущий домен (`open-pea-server.vercel.app`) и выделенный порт.
2. Если в течение **30 минут** на сервере нет игроков (`players == 0`), сессия автоматически закрывается при следующем обращении.
3. Для поддержания сессии активной игровой клиент или веб-панель может отправлять `POST /api/heartbeat` с JSON `{"id": "creative-...", "players": 1}`.

## Деплой
Загрузите содержимое архива (`main.go`, `go.mod`, `public/index.html`) в корень репозитория `PerrotSoft/open-pea-server` — Vercel автоматически соберёт и запустит проект.
