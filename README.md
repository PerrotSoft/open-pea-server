# Архитектура креатив-сервера с автовыключением через 30 минут

Поскольку Vercel работает по модели Serverless (функции живут несколько секунд), система разделена на 3 части:

1. **`orchestrator/` (Постоянно работающий демон на VPS)** — HTTP-менеджер на Go, который крутится 24/7 (через `systemd`), принимает запросы на запуск, выделяет свободный UDP-порт и запускает процесс креатив-сервера.
2. **`game-server/` (Игровой креатив-сервер)** — процесс на Go, слушающий UDP-порт. Внутри работает таймер: если активных игроков нет более **30 минут**, сервер корректно завершает работу и освобождает ресурсы.
3. **`web-vercel/` (Фронтенд и API-шлюз на Vercel)** — веб-страница с кнопкой и Go-функция, которая проксирует запрос к вашему постоянному оркестратору и возвращает игроку IP и порт.

---

## Быстрый запуск на сервере (Linux / VPS)

1. **Скомпилируйте игровой сервер и оркестратор:**
   ```bash
   cd game-server && go build -o game-server .
   cd ../orchestrator && go build -o orchestrator .
   ```

2. **Запустите постоянный оркестратор:**
   ```bash
   PUBLIC_HOST="ВАШ_БЕЛЫЙ_IP" API_SECRET="ваш-секретный-ключ" ./orchestrator
   ```
   *(Для постоянной работы в фоне используйте готовый юнит `orchestrator/creative-orchestrator.service` для systemd).*

3. **Деплой фронтенда на Vercel:**
   - Перейдите в папку `web-vercel/`.
   - В настройках проекта Vercel добавьте переменные окружения:
     - `ORCHESTRATOR_URL` = `http://ВАШ_БЕЛЫЙ_IP:8080`
     - `API_SECRET` = `ваш-секретный-ключ`
   - Выполните `vercel --prod`.
