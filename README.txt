Pengine Server (Go)
Запуск: windows\start.bat  /  linux: ./start.sh  (на своём ПК или на хостинге/VPS).
При старте печатает ваши локальные и внешний IP.
Лобби: http://IP:8080  — список комнат с ID. Хост регистрирует комнату: /register?name=Игра&port=27015&mode=Классика&map=Dust
(ответ содержит ID; повторять раз в 10 с). Узнать адрес по ID: /room/ID.
Ретранслятор: server -forward IP_хоста:27015 — игроки подключаются к IP этого сервера:27015.
Открыть порты: 8080/tcp и 27015/udp. Сборка: go build.
ВАЖНО: в самой игре пока нет кнопки «подключиться по ID» — вводите IP:порт вручную.
